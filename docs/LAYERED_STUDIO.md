# Layered Studio and graffiti emotes

## Controls and save files

All 59 shape tiles use the original shape geometry. Newly added shape layers use finer edges for opacity, outline, rotation and flips. The initial size fits the canvas and the default resize lock preserves proportions. For an earlier layer, select it in **Compose → Use smooth shape**. **Save & Use → Preview wall detail** shows the export using up to 256 decals for the entire artwork.

For handwritten lettering, start a text layer in **Flow** (Pacifico) or choose **Script** (Lobster). **Brush** uses Sedgwick Ave Display for a hand-lettered look. The editor preserves natural advances, baseline and overhanging strokes. Changing **Letter spacing** opens the joins. An earlier font layer keeps its saved rendering until you pick another face or press **Use natural lettering**. Undo restores the earlier version.

The smooth canvas preview covers upright Latin lettering in the 19 display faces, including supported accented letters. Pixel, text containing characters outside the smooth set, rotated or deformed lettering, outlines and very complex compositions use the ink preview. **Preview wall detail** shows the portable rendition used for premades, gallery copies and emotes. It fits up to 256 ink rectangles, so short words retain more detail than long phrases.

Open **Graffiti Lab → My Artwork & Emotes**. **Create new** starts a two-to-one canvas. **Start from premade or imported artwork** fits the project to the selected piece. The picker is the existing Artwork Library, with search, folders, favourites, recent items and Blackbook drawings. Select a card and use the orange action for the current task.

Each master has a stable project ID. Each layer has a stable ID inside that project. Masters live under `studio/projects/`; the recoverable draft is `studio/draft.json` in the plugin data folder. A saved master contains its own image pixels, editable text, shape parameters, paint-layer pixels and a composite thumbnail. Moving a source file later does not invalidate the master. The Studio saves the draft after editing pauses and on normal close. Save failures are shown. Starting or opening a different project first saves the current master.

Existing Blackbook files, imports, gallery downloads, wall-paint saves and placements retain their formats. Opening older artwork creates a separate image layer. For animated source art the Studio imports the first displayed frame. The loadout can equip compatible multi-frame imports and Blackbook artwork directly. Saving a premade uses the title and a content fingerprint. Earlier placements and equipped slots keep the version they were given.

Saved text retains its spelling, case, punctuation, line breaks and preset. Earlier Studio text layers keep their original glyphs until you choose a new font or type an extended character. All presets share a broad Unicode fallback. A missing glyph appears as a box and the editor displays a notice. The pinned game input directly encodes characters in the Basic Multilingual Plane. For emoji sequences, complex script shaping, or a font installed on your PC, choose **System fonts and emoji…**, open **Import Artwork.html** and select **Type lettering with system fonts**. Preview and save the resulting artwork into My imports. This route creates an image layer.

Freehand is a 96 × 48 pixel layer with no stroke-counter limit. The preview and wall export use the same 16-ink rectangle list, starting at 96 cells on the longer edge for new lettering or 64 for other projects. Detail steps down to fit 256 rectangles. Short lines and larger letters retain the most detail. This development build keeps up to 40 in-session undo actions. Disk limits on the pinned host are 1 MiB per file and 1,000 files per plugin.

## Emote rendering and session delivery

In **Premade Art**, choose a bundled piece or open **My imports** for personal premades, collection items, reshaped copies and gallery downloads. Select **Use as emote** (M or Y), choose a slot and confirm **Equip**. **Saved Gallery → Emote** works for Blackbook drawings. **Emote Loadout → Choose artwork for this slot** also lists saved Studio projects. You can equip personal artwork during a session. Picking a slot stores a snapshot, so an emote still works if its original is later edited or removed.

Built-in pieces use their packaged atlas thumbnails. Custom pieces use up to 20 × 20 cells and 64 ink rectangles per frame. A fine mark contributes ink even when it falls between cell centres. Nearby details can merge at this size. Animated pieces keep their frame timing. Equipping saves the rendition to `studio/emotes.json`. A Studio master can be equipped directly without creating an import or publishing it.

Each client reads the local head joint or the sending peer’s head joint. When the head is unavailable it tries the spine with extra clearance. The renderer projects the anchor above the joint, skips positions behind the camera or beyond 25 m, and scales the art proportionally. The screen-space overlay has no native per-pixel depth test. A collision probe to the anchor suppresses it behind solid geometry, checked at 5 Hz. A partly covered image can still extend past the edge of a wall. Up to four emotes are drawn at once. The default cooldown is six seconds, adjustable from one to thirty. Activations expire after five seconds. Players can hide incoming emotes.

The new `session.skaters` permission is required for `session.joint(player, "head")`. The packet uses the transport’s sender ID, current session world and map, activation sequence, rendition fingerprint and the selected art. Custom frames fit together in one bounded packet under the 4,082-byte transport ceiling. Each activation is self-contained, including for a cold recipient. A truncated or invalid message is discarded. Repeating the emote sends a fresh complete rendition. Validated renditions are cached in memory. The public gallery is outside this flow. Compatible peers render their own copy above the sender. ## Acceptance checks

**In ReSkate 0.9.0 development testing, 23 November 2026.** At Blue Light Beach in San Vansterdam, a tester combined an orange circle, editable lettering and white freehand details. The stored premade appeared in My imports. Placing it on concrete beside an existing Switchback returned to Save & Use. The placed artwork and the older Switchback were both visible with the menu closed. Reopening the saved thumbnail restored the separate Circle, Lettering and Paint layers. The same custom artwork displayed above the stationary local skater from wheel slot 1 and disappeared after activation. This test used one game client.

**Automated artwork and UI checks.** The local overlay accepted packaged artwork, a new freehand drawing, a new import and a mixed project. The UI exercise added two shapes, lettering and paint, toggled visibility and locking, reordered and nudged a layer, undid and redid a stroke, reopened the master, placed its export and used the emote loadout. Existing import, gallery, reshape, placement, sharing and persistent wall-paint regressions were also exercised.

The Luau source-picker regression equipped all 46 bundled designs, a one-pixel import, a reshaped copy, a collection item and an animated gallery download. It exercised the Premade Art, Saved Gallery and loadout controls, a saved Studio master with no export and a Blackbook animation with a blank first frame. It reopened the saved slots and checked that a damaged source preserved the previous assignment. These checks used a simulated ReSkate host.

With the normal game camera restored, loading slot 1 again displayed the saved custom rendition. It stayed above the cap as the camera and skater turned and disappeared on expiry. The speedometer read zero during the captured turn.

**Awaiting live checks.** On a controller, open the wheel with Back + X while rolling, select the test piece and press A. Continue steering, crouch and bail. Check that the wheel releases input immediately and the art stays over the moving head until it expires. Repeat beside and behind a solid wall with an observing player, using the two-client procedure below. Moving anchors and obstructed views have been exercised with simulated host data.

The Luau regression `tests/test_composition_emotes.py` exercises a shape, editable word, freehand marks and a new import in one composition, saves and reopens it, compares its exported rectangles, and checks the persistent emote assignments. A separate Luau process starts with an empty private store and receives only the activation packet. It verifies sender tracking, a moving head, missing joints, range of camera visibility, obstruction, expiry, stale messages and departure. It exercises the plugin logic against host fixtures.

For a two-client game check, install the same development build and approve its permissions on both PCs. Join the same map and session. On player A, create a new layered piece with a distinctive word and a paint detail. Save the project, reopen it, move the word, save a premade and equip it in slot 3. Leave player B’s library empty and keep **Other players’ emotes** shown. Trigger slot 3 while skating, turning, crouching and bailing. On B, check that the piece follows A, clears the face and expires after five seconds. Repeat from B so A can verify the sender in the opposite direction. Check behind a solid wall and repeat with a built-in premade, a freehand drawing and an imported image. Finally hide incoming emotes, change map and leave the session. A real two-client run is awaiting verification.
