# ReSkate API findings

Baseline checked on 21 November 2026. **Local evidence** comes from inspected files, installed examples and live offline playtests. **Documented** means the upstream project describes the capability. [First placement test](MILESTONE_1.md) · [Three-design selector test](MILESTONE_2.md)

## Local evidence

- ReSkate build 20261116 checks numeric input before named keys. Passing `"0"` to `reskate.input.key` is interpreted as virtual-key code zero and raises an error. Use `0x30` for the top-row 0 key. In the 0.8.0 offline playtest, polling `"0"` stopped Graffiti Lab as soon as Birds entered placement mode. With `0x30`, Birds previewed and placed on the Blue Light Beach shop wall in San Vansterdam, and Premade Art reopened with Birds selected. The Luau menu regression also checks resizing, rotation and reset before confirmation. [ReSkate key-code binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_services.cpp#L217-L230)

- The repository started without Git metadata, a plugin manifest, runtime scripts or game artwork. The pre-existing `work/` and `outputs/` held the earlier feasibility report and its working files.
- The installed `ReSkateLauncher.exe` and `ReSkate.dll` both report `20261116`. The prior feasibility check matched the local `Skate.exe` SHA-256 to the upstream pin. ReSkate targets game build `20260929`, Steam build `25414733`. [Runtime release](https://github.com/Dingo-Shenanigans/ReSkate/releases/tag/20261116) · [Supported build pin](https://github.com/Dingo-Shenanigans/ReSkate/blob/main/Engine/Game/Build/supported_build.h)
- Two installed `Mods/` folders, `TurboTokenArcade` and `TheSpotHB-TheSpotOverlay`, have a root `reskate-plugin.json` with `api: 1`, `side: "client"`, a permissions list and `entry: "plugin/main.lua"`. In the inspected copies, TurboTokenArcade reads `reskate.level.current()` at line 585 of its entry. TheSpotOverlay sends a server message at line 17 and registers its message handler at line 236.

The pinned plugin host allows 32 distinct overlay pictures per plugin, 128 declared effects per plugin and 32 shader depots per resident entry. It checks each matching bundle entry when resolving a resident shader. Graffiti Lab 0.6.6 uses one UV-mapped thumbnail sheet and two resident entries for its 62 decal materials. [Overlay image budget](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_vm.h#L53) · [Effect declarations](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_manifest.cpp#L141) · [Resident limits](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Engine/Vfs/resident_assets.h#L39) · [Shader lookup](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Engine/Vfs/mod_list.cpp#L543)

## Documented capabilities

| Area | What the API exposes | Implication for Graffiti Lab |
| --- | --- | --- |
| Runtime and packaging | The host loads sandboxed Luau from a manifest in an enabled mod under `Mods/`. Users approve plugins. A Thunderstore ZIP uses `manifest.json`, `README.md` and `icon.png` alongside the mod contents, and published plugins belong in the Plugins category. | Use ReSkate's plugin host. Keep the offline asset-authoring tools outside the player package. | Surface queries | `reskate.camera.get()` provides the view. `reskate.world.probe(from, to)` distinguishes hit, clear and unavailable. A hit carries position and fraction. `reskate.world.pick` can also identify a hit object. | Start with short local probes. Estimate a plane from multiple hits. A basic probe has no surface normal or material ID. Body-based `probe_batch` can return a measured normal under additional conditions. [Camera](https://docs.reskate.dev/plugins/api/camera) · [World](https://docs.reskate.dev/plugins/api/world) · [Body queries](https://docs.reskate.dev/plugins/api/bodies) |
| World artwork | `reskate.effects.decal` creates a projected decal from a declared, compiled decal volume template. `move` updates an unattached decal, `opacity` sets its alpha, and `release` removes it. | Build the material, textures and shader dependencies. | UI and input | `reskate.ui.screen` can own input while the draw callback renders the selector. `d:image` reads a packaged PNG. `reskate.input.bind` registers player actions. | Verified in game with three real thumbnails, a larger preview, mouse selection, Enter and the Ctrl+L library action. The wall preview separately uses a compiled decal template. [Screen binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_world.cpp#L3391-L3447) · [Draw binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_ui.cpp#L164-L192) |

In a live 0.6.2 test on Turbo Token Arcade, the prompt appeared after the library closed. With a test camera aimed at the arcade wall, the ring turned green, Switchback appeared in preview and one left click placed one decal. The game displayed “Placed Switchback”. | Plugins menu | A plugin with the `menu` permission can register a page with `reskate.menu.page` and render a button with `ui:button`. Custom screens draw behind the native menu. [Menu binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_ui.cpp#L383-L404) · [Overlay draw order](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_overlay.cpp#L618) |

Documented limits are 1 MB total for storage, and 1 MB per file with up to 1,000 private files. ## Menu navigation playtest

In 0.6.3 on Turbo Token Arcade, **Open Graffiti Lab** in the Plugins menu opened the five-choice dock after Insert dismissed the native menu. All five destinations opened by mouse, Esc returned from each to the dock, and Saved Gallery displayed the existing **ridge line** drawing. The automated Luau navigation test also checks controller input, 720p hitboxes, search and category filters, editor erase/undo, shared can settings and the offline tool restrictions. The packaged headings use one 512 × 512 PNG atlas and the draw image style’s four UV coordinates. [Image style binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_ui.cpp#L76-L87)

## Known limits

- **Hosting alone.** Build 20261116 reported one player in a two-slot lobby while the client plugin still saw `session.active() == false`. The host's plugin session becomes active after a peer handshake. The game already supplies a world ID while hosting alone, so Graffiti Lab records the world with the confirmed premade and checks it when the first peer connects. Local Echo is explicitly excluded from the plugin session. [Session feed](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_runtime.cpp#L156-L169) · [Handshake flag](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Multiplayer/Session/session_view.cpp#L348-L357) · [Session world](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Multiplayer/Session/session.cpp#L376-L412)

- **Persistent wall ink.** The pinned host reads and writes length-delimited byte strings, creates private subfolders, and writes via a temporary file followed by rename. It limits each file to 1 MiB, the plugin data directory to 1,000 files, and file API calls to 64 per second. Graffiti Lab stores up to 2,048 fixed-size paint samples per page and checks the full map name on load. [File bindings](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_throwdowns.cpp#L107-L143) · [File implementation](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_game_runtime.cpp#L852-L912)

- **Painting at the pointer.** The host projects camera-space coordinates using vertical field of view, viewport height and the camera's right, up and forward axes. Wall Paint inverts that projection and calls the existing wall queries at each sampled pixel. The screen-owned cursor supplies pixel position and left-button state. This path reuses the installed ink templates and existing manifest permissions. [Pinned projector](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_camera.h#L44-L66) · [Camera axes](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_game_runtime.cpp#L1883-L1889) · [Cursor binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_world.cpp#L3471-L3494) · [Wall Paint checks](MILESTONE_5.md)

- **Editable drawings.** In the target build, `reskate.files.list/read/write` use plugin-private files. The write call reports the result after replacing the file from a temporary sibling. Listing the directory builds the gallery index, so each save updates one file. In a new game process the same file returned all saved colours, widths and point coordinates. [Runtime implementation](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_game_runtime.cpp#L852-L914) · [Blackbook restart test](MILESTONE_3.md)
- **Editor overlays.** A packaged draw image is limited to 512 × 512 pixels. The initial 1152 × 576 checkerboard was rejected in-game. A 384 × 192 PNG scaled to the same canvas rendered successfully. Cursor position and button state are available while the plugin screen owns input. [Image loader](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/UI/Overlay/plugin_images.cpp#L64-L76) · [Input binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_world.cpp#L3471-L3494)

- On the tested build, the projected decal displayed the original image, alpha and orientation on two solid receivers. A Blue Light Beach grille passed the footprint probes but only its visible bars received paint. Geometry that looks perforated can have a solid collision shape.
- A fixed wall can return an object from `world.pick`, with an optional blueprint and transform. Starting in 0.8.2, both wall tools use the hit position, local surface angle and collision at the four corners of the artwork. Map and object names no longer affect eligibility. The eight-metre reach is measured from the camera. Collision can differ from visible geometry, particularly on grilles. [Pinned pick implementation](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_world.cpp#L692-L730) · [Observed surfaces](MILESTONE_1.md)

- In the 0.8.2 offline test on 2026-11-22, Wall Paint showed a hollow aiming ring on an unusable edge at Blue Light Beach in San Vansterdam, then registered an orange dab on the flat face of the gateway support. The full-size Switchback preview fitted a broader nearby wall and placed successfully. On the custom Schoolyard map, the door-side wall accepted an orange dab, a 0.12 m freehand stroke (six samples), and a full-size Switchback. The selector reopened after placement on both maps. An offline test camera framed the walls for the premade checks. Placement used the regular in-game controls.
- A later visit picked the same metal kiosk panel at two heights under `Levels/Game/BAM_LevelRoot/generated/StairsLitePG_AGAsset_B8E7EE88`. The earlier name-based filter needed a second entry for that panel. The current geometry check accepts either name. [Selector test](MILESTONE_2.md)
- Collision is streamed near the skater. World queries allow up to 64 rays per tick and a 1,000 m segment. A clear ray far from the skater gives no assurance about unloaded geometry. [World queries](https://docs.reskate.dev/plugins/api/world)
- A plugin may hold up to 2,048 decals, with 4,096 shared globally. A handle lasts at most ten minutes. Loading, replay, Noclip and park editor transitions may release effects earlier. Premade and Blackbook artwork have a 16-placement cap and one preview. Freehand paint stores samples independently, prioritising nearby ink when the engine runs out of decal slots. The pinned binding returns `effect limit reached` at the per-plugin limit. The global limit or an unavailable renderer can instead return `effect asset or renderer unavailable`. [Plugin binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_effects.cpp#L60-L71) · [Renderer allocation](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Rendering/plugin_effects.cpp#L221-L232) Three simultaneous marks were exercised. Frame cost at the cap is unmeasured. [Effect lifetime and limits](https://docs.reskate.dev/plugins/api/effects) · [Selector test](MILESTONE_2.md)
- ReSkate enforces plugin time and memory budgets. Its release notes specify 128 MB of plugin memory on this build. Verify frame cost and mark count on both test maps. [Runtime limits](https://docs.reskate.dev/plugins/limits) · [Build notes](https://github.com/Dingo-Shenanigans/ReSkate/releases/tag/20261116)

## Local spray animation on ReSkate 20261116

- The right upper arm is joint 47 and the right hand is joint 49. The plugin reads the shoulder using `skater.joint`, sets a short-lived local pose with `skater.reach` and anchors the can at the base of the right middle finger (joint 54), where the fingers meet the palm. Releasing a reach uses `skater.reach(nil)`. These calls require `skater.read` and `skater.animation`. [Arm chain](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Skater/arm_reach.h#L19-L26) · [Reach](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_world.cpp#L1532-L1562) · [Grip joint](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Skater/skater_skeleton.h#L31-L38)
- In 0.6.11 Studio compiles the original `art/spray-can/can.glb` into a rigid mesh and an ObjectBlueprint. The package carries their geometry, three textures, material variation and shader dependencies in the shared root bundle. The local paint can uses the right middle-knuckle joint (54) with rotation enabled and collision disabled. ReSkate reported the native object in San Vansterdam and the model followed the glove as the aim moved. [Native entity attachment](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_world.cpp#L555-L649)
- The spray mist uses an original feathered texture and short-lived puffs at the nozzle and wall. ReSkate projects each world image using the active camera. Only the puffs use this overlay, which can draw through foreground geometry. The can uses the game’s mesh renderer. [World-image renderer](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/UI/Overlay/plugin_overlay.cpp#L569-L581)

## Public gallery

- ReSkate enforces a maximum of four registered screens per plugin. Opening Public Artworks as a fifth screen raised an error in-game. Sharing one input screen between the editor and Wall Paint allowed the gallery to open from the main menu. [Screen registration](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_world.cpp#L3392-L3404)
- With the gallery hostname declared in the manifest and Web permission enabled, a player skating offline in San Vansterdam could browse, publish and download over HTTPS. Two independent gallery credentials on one installation completed the transfer through the live Worker and D1. [Live test and remaining checks](../service/gallery/README.md#live-graffiti-lab-test)

## Unresolved questions and how to test them

1. **How does the decal behave behind other geometry?** The core playtest confirmed orientation, alpha, lateral camera movement and removal. Occlusion by a separate foreground object and projection through thin partitions still need a dedicated test. [Playtest record](MILESTONE_1.md)
2. **Which other receivers are reliable?** Test corners, rails, additional materials and missing collision on a stock and a custom map. Record results by full level name and compare visible geometry with collision.
3. **How much detail can a live drawing retain?** Milestone 4 verified rendering saved strokes with 16 precompiled palette materials and a bounded set of rectangular decals. The host accepts a private asset name and an orthogonal world transform. The reviewed creation binding exposes attachment and lift. Arbitrary runtime pixel uploads and per-instance colour tint remain unverified. An offline art pack can preserve a higher-resolution raster at the cost of a rebuild and installation. [Pinned effect binding](https://github.com/Dingo-Shenanigans/ReSkate/blob/8e4aefca153ce9cb622074ae4de05f81fa71d09c/Extension/Plugins/plugin_api_effects.cpp#L32-L78) · [Wall results](MILESTONE_4.md)
4. **What counts as a shared piece?** Test a matching art pack, a missing artwork ID and a late joiner. Determine whether sharing custom pieces also requires distributing stroke records or image data. [Session transport](https://docs.reskate.dev/plugins/api/session)
